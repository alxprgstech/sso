# Сканирование секретов

`detect-secrets==1.5.0` проверяет tracked и новые файлы, не исключённые `.gitignore`. Скрипт `python scripts/check_secret_scan.py --self-test` сравнивает тип, путь и hash находки с `.secrets.baseline`. Новая находка приводит к exit 1; значение в вывод не попадает. Контрольный образец генерируется случайно в краткоживущем файле и проверяет, что сканер действительно срабатывает.

Baseline создан 26.09.2026 после просмотра **путей и типов** первоначальных 58 сигналов в 16 файлах. После подготовки нынешнего акта добавились 3 сигнала: строка CI, запускающая сам scanner, и два публичных hash идентификатора ревизии в `acceptance-goal-09.json`; эти три строки проверены по содержимому как ложноположительные и включены отдельно. Сейчас 61 fingerprint в 17 файлах. В baseline нет текста значений. Его наличие не доказывает, что первоначальные 58 значений проверены владельцем или что утечки исключены; перед общей приёмкой нужна приватная проверка каждого из них. Новые файлы приложения не получают автоматического исключения. Обновлять baseline можно только после отдельного разбора сигналов; команда `--write-reviewed-baseline` ограничена перечисленными fixture-файлами и сама по себе не считается аудитом.

Проверка внешнего комплекта и истории Git этим скриптом не выполняется. Перед выпуском нужно отдельно просканировать артефакты и проверить, что реальные ключи отсутствуют в истории/логах. Запрещено помещать реальные секреты в baseline.
