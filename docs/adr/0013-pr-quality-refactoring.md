# ADR-0013: layout cookies и разделение проверяемых сценариев

Дата: 2026-10-03. Статус: принято. Требования: UI-05, PRIV-01..09, CI; задачи PR-FIX-02.

## Причина

Измерение fixed-баннера с ResizeObserver оставляет промежуток между изменением viewport и обновлением CSS reserve. Реальный CI и локальный probe выявили расхождение 105.19 px. CodeScene также обнаружил смешение разбора ввода, проверок, транзакций и отображения в крупных функциях.

## Решение

Баннер занимает отдельную нижнюю строку flex-контейнера высотой viewport; содержимое прокручивается в соседней строке. CSS вычисляет обе высоты в одном layout, JavaScript не резервирует место. Управление согласиями и фокусом разделяется на небольшие операции. API получает типизированный контекст зависимостей; сценарии backend остаются координаторами тех же транзакций и проверок. Миграция сохраняет явный DDL и порядок, эксплуатационные команды выделяют подготовку, исполнение и очистку.

## Альтернативы и последствия

Ожидание двух кадров или повтор теста скрывает зависимость от расписания и не исправляет layout. Изменение порогов CodeScene либо suppression не исправляет сложность. Новых зависимостей нет. Контракты API, защита, UTC deadlines, блокировки, UV, одноразовость и default-off flags сохраняются; проверяются регрессиями на PostgreSQL и в браузере. Обновлённый тест измеряет геометрию в одном browser evaluation и проверяет выделенную нижнюю строку вместо удалённого padding reserve.
