- Версия: 1.0.0

## 1. Введение

Настоящий документ определяет профиль применяемых стандартов при разработке, документировании, обеспечении безопасности и приёмке программного комплекса ALXPRGS SSO. В документе зафиксированы стандарты Единой системы программной документации (ЕСПД / ГОСТ 19), международные спецификации IETF/W3C/OpenID Foundation и отраслевые практики.

### 2.1. Допустимые отклонения и ограничения формата Markdown
- Документация ведётся в формате Markdown (UTF-8) в репозитории системы контроля версий Git.
- В связи с электронным форматом хранения документов (Markdown) не воспроизводятся формальные типографские рамки, листы утверждения с физическими подписями, графы основной надписи по ГОСТ 19.104-78.
- Вместо физических подписей версионный контроль и авторство обеспечиваются криптографическими средствами Git commit SHA и журналом разработки `docs/worklog.md`.
- Проект не заявляет прохождение государственной сертификации или формальной аттестации ФСТЭК/ФСБ, если это не зафиксировано отдельным поручением владельца.
