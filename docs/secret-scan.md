# Сканирование секретов

Сверка документации: 06.10.2026, продукт 0.2.0. [Реестр и границы](index.md), [статус](status.md). Прежние измерения/PASS относятся к указанным датам и ревизиям.

`detect-secrets==1.5.0` проверяет tracked и новые файлы, не исключённые `.gitignore`. Скрипт `python scripts/check_secret_scan.py --self-test` сравнивает тип, путь и hash находки с `.secrets.baseline`. Новая находка приводит к exit 1; значение в вывод не попадает. Контрольный образец генерируется случайно в краткоживущем файле и проверяет, что сканер действительно срабатывает.

При новых находках скрипт выводит только путь, тип и число сигналов в группе; значения и fingerprint в CI-лог не попадают. Сканер запускается с `PYTHONUTF8=1`: без этого Windows пропускал целые UTF-8 файлы с кириллицей из-за ошибки декодирования. Регрессионный тест проверяет файл с кириллическим комментарием и синтетическим секретом. Тест аудита администратора создаёт пароль во время выполнения для bootstrap, входа и повторной аутентификации.

Baseline создан 26.09.2026 после просмотра **путей и типов** первоначальных 58 сигналов в 16 файлах. Три последующих сигнала (строка CI и публичные SHA в акте) были разобраны как ложные; один публичный SHA затем заменён проверенным по `git rev-parse HEAD`. Удалённый [CI 36445914754](https://github.com/alxprgstech/sso/actions/runs/36445914754) показал 55 сигналов, ранее пропущенных Windows. Их пути, типы, строки и контекст проверены: локальные/example DSN, документационные примеры, синтетические пароли и client secrets тестового контура, фиксированные PKCE и криптографические test vectors. Реальных production credentials среди этих 55 не выявлено. После включения UTF-8 и этого разбора baseline содержит 116 fingerprint в 39 файлах; повторный локальный скан дал 0 новых. Отдельный временный синтетический секрет по-прежнему должен давать exit 1 без значения в выводе.

Baseline не содержит текст значений. Первоначальные 58 сигналов по-прежнему требуют приватной проверки владельца перед общей приёмкой: их наличие в baseline не доказывает отсутствие утечки. Новые файлы не получают автоматического исключения; `--write-reviewed-baseline` ограничен перечисленными проверенными путями и сам по себе не считается аудитом.

Проверка внешнего комплекта и истории Git этим скриптом не выполняется. Перед выпуском нужно отдельно просканировать артефакты и проверить, что реальные ключи отсутствуют в истории/логах. Запрещено помещать реальные секреты в baseline.

## Baseline сегодня

Числа 58/116 выше — исторические этапы. Текущий набор — .secrets.baseline; результаты каждого запуска фиксируются отдельно. Baseline не проверяет действительность credentials и не закрывает owner-review истории.
