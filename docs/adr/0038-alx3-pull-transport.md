# ADR-0038. Публикация проверенного пакета для ALX-3

Дата 20.11.2026. Задача CD-ALX3-PULL-01.

SSO перенесён на ALX-3. GitHub Actions продолжает собирать и проверять
существующий неизменяемый transport для актуального main. Режим
`ALXPRGS_DELIVERY_MODE=pull` завершает workflow отчётом о публикации.
ALX-3 сам запрашивает пакет с полномочиями на чтение.

Повторное использование transport сохраняет общий драйвер, привязку
к ревизии и существующую проверку образов. Для прямого SSH с GitHub-hosted
runner пришлось бы открывать ALX-3 для входящих подключений. Отдельная
сборка увеличила бы время CI и объём хранилища. Применение пакета и откат
на общем PostgreSQL проверяются в эксплуатационном контуре ALX-3.
