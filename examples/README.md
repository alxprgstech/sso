# Демонстрационные клиенты ALXPRGS SSO

В этом каталоге представлены два независимых клиентских приложения на базе FastAPI и Python SDK `alxprgs-sso`, демонстрирующие механизм единого входа (Single Sign-On).

## Клиенты

1. **Сервис 1 (Портал аналитики)**: `examples/client1/app.py`
   - `CLIENT_ID`: `client_analytics_app`
   - `REDIRECT_URI`: `http://localhost:8001/callback`
2. **Сервис 2 (Портал документации)**: `examples/client2/app.py`
   - `CLIENT_ID`: `client_docs_app`
   - `REDIRECT_URI`: `http://localhost:8002/callback`

## Сценарий бесшовного единого входа (Single Sign-On)

1. Пользователь открывает **Сервис 1** (`http://localhost:8001/`) и нажимает «Войти».
2. Сервис 1 генерирует PKCE `code_verifier` и перенаправляет пользователя на сервер SSO (`http://localhost:8000/oauth/authorize`).
3. Пользователь вводит логин и пароль на сервере SSO.
4. Сервер SSO выпускает одноразовый authorization code и возвращает пользователя в Сервис 1 (`/callback`). Сервис 1 обменивает код на Access/ID токены и авторизует пользователя. Сервер SSO сохраняет защищённый host-only сессионный cookie.
5. Пользователь открывает **Сервис 2** (`http://localhost:8002/`) и нажимает «Войти».
6. Сервис 2 перенаправляет браузер на сервер SSO (`/oauth/authorize`).
7. **Единый вход (SSO)**: Сервер SSO видит валидную активную сессию пользователя и **моментально** перенаправляет браузер обратно в Сервис 2 с новым кодом авторизации, **без повторного запроса логина и пароля**!
8. Пользователь авторизован в обоих независимых сервисах.

## Запуск примеров

```bash
# Терминал 1 (Сервер SSO)
uvicorn app.main:app --port 8000

# Терминал 2 (Сервис 1)
python -m uvicorn examples.client1.app:app --port 8001

# Терминал 3 (Сервис 2)
python -m uvicorn examples.client2.app:app --port 8002
```
