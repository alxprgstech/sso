# ADR 0001: Выбор технологического стека бэкенда, фронтенда и СУБД

> Сверка 06.10.2026: сохранено решение на дату принятия; это не новый результат приёмки. Действующий профиль: [архитектура](../architecture.md), [API](../api.md), [статус](../status.md).

- **Статус**: Принято
- **Дата**: 2026-09-24T11:38:00+03:00
- **Исполнитель**: Antigravity

## Контекст

Проект ALXPRGS SSO создается как высоконадежная, безопасная система единого входа для закрытой инфраструктуры с возможностью научных исследований. В соответствии с требованиями `GOAL.md` и `AGENTS.md`, система должна использовать:
- Язык Python для бэкенда;
- Веб-фреймворк FastAPI;
- СУБД PostgreSQL;
- Фронтенд на React + TypeScript;
- Отдельно устанавливаемый Python SDK.

## Решение

1. **Backend**:
   - Язык: **Python 3.12+** (с поддержкой 3.13).
   - Фреймворк: **FastAPI** (асинхронный ASGI, валидация входных данных через **Pydantic v2**, автоматическая генерация OpenAPI схемы).
   - Работа с базой данных: **SQLAlchemy 2.0** в асинхронном режиме (`asyncpg` / `psycopg3`) с синхронным драйвером для утилит миграций.
   - Миграции схемы данных: **Alembic**.
   - Управление зависимостями и сборкой: стандартный `pyproject.toml` (совместимый с `hatchling` / `pip` / `uv`).

2. **Database**:
   - **PostgreSQL 16+**. Использование реляционной целостности, внешних ключей, строгих транзакций и атомарных операций (`UPDATE ... RETURNING ...`) для гарантированного предотвращения race conditions при погашении токенов и кодов.

3. **Frontend**:
   - **React 18+**, **TypeScript**.
   - Сборщик: **Vite** для быстрой сборки и оптимизированного production bundle.
   - Стилизация: чистый CSS / современные CSS modules для минимизации внешних непроверенных зависимостей.

4. **Python SDK**:
   - Изолированный пакет в `packages/python-sdk`, зависящий только от стандартных сетевых/криптографических библиотек (`httpx`, `pyjwt`, `cryptography`) и опционально `fastapi` для зависимости проверки токенов. Не импортирует внутренние модули сервера.

## Альтернативы и аргументация

- *Django + Django REST Framework*: более тяжеловесный монолит, избыточный ORM и админка, сложность тонкого асинхронного контроля протокола OIDC. Отклонено в пользу FastAPI.
- *Node.js / Go*: отклонено требованиями ТЗ (требуется Python).
- *SQLite*: категорически запрещено для интеграционных тестов правилами AGENTS.md, так как SQLite не поддерживает строгую модель блокировок и конкурентных транзакций PostgreSQL.

## Последствия

- Высокая скорость разработки и строгая типизация (mypy / pyright, TypeScript).
- Гарантия совместимости и воспроизводимости окружения.
