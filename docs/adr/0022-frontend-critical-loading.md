# ADR-0022 — критический путь загрузки frontend

Статус: принято для WEB-PERF-01 по поручению владельца об оптимизации Lighthouse.

Критический путь входа включал SDK Sentry даже при выключенной диагностике, Radix dialog, отдельный файл токенов темы и последовательные запросы возможностей/сессии. Длинного HTTP cache для файлов с хешем не было.

Решение: лёгкий telemetry facade проверяет серверную конфигурацию и согласие перед динамической загрузкой runtime SDK. После загрузки и при смене согласия повторяются проверки, generation guard отклоняет устаревшую инициализацию. Runtime сохраняет transport/sanitization/Replay guards; локальный React ErrorBoundary показывает прежний fallback и отправляет только безопасную обобщённую ошибку через facade. SDK инициализируется асинхронно, тестовый harness ожидает завершение. Исключения до включения диагностики не буферизуются. Dialog загружается при показе, reauthentication handler регистрируется синхронно. Возможности и текущая сессия читаются параллельно, gate ждёт обе операции. Токены CSS входят в версионируемую сборку, основной шрифт получает preload.

Кэш: успешные hashed assets JS/CSS/WOFF2 — один год; mutable brand/theme — один час; HTML shell и прочая статическая раздача — revalidation. Проксируемые API/OAuth не получают эту политику. Используется Nginx `expires`, чтобы сохранить наследование всех security headers. `.map` остаются недоступны, неизвестные asset paths возвращают 404.

Альтернативы: eager SDK сохраняет лишнюю загрузку при default-off; удаление SDK нарушает функциональные требования; inline theme bootstrap потребовал бы изменения CSP, поэтому маленький синхронный theme script сохранён для корректной темы до первого кадра. Смена browser target не устраняет polyfills стороннего SDK и не обоснована поддерживаемыми браузерами.

Проверка: local real Nginx HTTP, browser UI/CSP/cache/UTF8, telemetry consent/revocation/real SDK transport, компоненты и одинаковые CDP cold samples. CDP измерения не считаются результатом Lighthouse или production. Серверные auth/security guards не изменяются.
