# Сканирование секретов

`detect-secrets==1.5.0` проверяет tracked и новые файлы, не исключённые `.gitignore`. Скрипт `python scripts/check_secret_scan.py --self-test` сравнивает тип, путь и hash находки с `.secrets.baseline`. Новая находка приводит к exit 1; значение в вывод не попадает. Контрольный образец генерируется случайно в краткоживущем файле и проверяет, что сканер действительно срабатывает.

При новых находках скрипт выводит только путь, тип и число сигналов в группе; значения и fingerprint в CI-лог не попадают. После изменения теста аудита администратора синтетический пароль создаётся во время теста и используется для bootstrap, входа и повторной аутентификации. Локальный прогон 28.09.2026 на Windows с `detect-secrets==1.5.0` дал 61 сигнал и 0 новых; отдельный временный синтетический секрет привёл к exit 1 без раскрытия значения. Присланный ранее Linux CI лог (117/56) не подтверждён на текущем рабочем дереве; требуется повторный удалённый прогон на итоговом SHA.

Baseline создан 26.09.2026 после просмотра **путей и типов** первоначальных 58 сигналов в 16 файлах. После подготовки нынешнего акта добавились 3 сигнала: строка CI, запускающая сам scanner, и два публичных hash идентификатора ревизии в `acceptance-goal-09.json`; эти строки проверены по содержимому как ложноположительные. При обновлении `base_sha` для TASK-092 один старый публичный SHA заменён текущим подтверждённым `git rev-parse HEAD` SHA; это отдельное разобранное ложное срабатывание. Сейчас по-прежнему 61 fingerprint в 17 файлах. В baseline нет текста значений. Его наличие не доказывает, что первоначальные 58 значений проверены владельцем или что утечки исключены; перед общей приёмкой нужна приватная проверка каждого из них. Новые файлы приложения не получают автоматического исключения. Обновлять baseline можно только после отдельного разбора сигналов; команда `--write-reviewed-baseline` ограничена перечисленными fixture-файлами и сама по себе не считается аудитом.

Проверка внешнего комплекта и истории Git этим скриптом не выполняется. Перед выпуском нужно отдельно просканировать артефакты и проверить, что реальные ключи отсутствуют в истории/логах. Запрещено помещать реальные секреты в baseline.
