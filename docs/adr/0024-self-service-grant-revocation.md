# ADR-0024: самостоятельный отзыв OIDC-грантов

Дата: 20.10.2026. Статус: принято для SSO-SEC-0002 (#16).

Ранее logout и self-revoke удаляли только browser sessions; refresh продолжал работать. Старый API-контракт это допускал, но пользователь не мог остановить украденный refresh без смены пароля.

Успешный logout (API и RP-initiated), удаление принадлежащей пользователю сессии и revoke-others теперь атомарно отзывают все refresh и authorization codes пользователя. Account-first lock сериализует отзыв с обменом/ротацией. Удалённые refresh строки сохраняются как replay evidence. Browser sessions сохраняются согласно выбранной операции; security_revision не меняется. Невалидный/чужой session_id не отзывает grants.

Схема не связывает grants с устройствами. Консервативный global scope явно указан в API/security документах. Альтернативы: session_id FK и миграция legacy grants либо отдельный экран приложений. Они сложнее, требуют нового lifecycle/API/UI и не нужны для немедленного безопасного self-service отзыва. Оставить только документацию недостаточно для реакции на кражу refresh.

Самостоятельно проверяемые ранее выданные JWT остаются действительными до exp (до300с), включая UserInfo при неизменной revision. RP закрывает свою локальную сессию самостоятельно; back/front-channel logout не добавлен.
