## 1. Общие сведения

1. **Наименование**: ALXPRGS Single Sign-On (ALXPRGS SSO).
2. **Назначение**: Централизованная система идентификации, единого входа и управления учетными записями.
3. **Используемые языки и платформы**:
   - Backend: Python 3.13, фреймворк FastAPI, асинхронный ORM SQLAlchemy 2.0 (`psycopg` async driver);
   - СУБД: PostgreSQL 16;
   - Frontend: TypeScript, React 18, Vite;
   - Программный SDK: Python пакет `alxprgs-sso` (локальные wheel/sdist; публичная публикация не подтверждена).

## 3. Используемые криптографические алгоритмы и методы

1. **Хеширование паролей**: Argon2id (RFC 9106) с индивидуальной случайной солью (16 байт) и параметрами `time_cost=3`, `memory_cost=65536 KB`, `parallelism=4`.
2. **Асимметричная подпись OIDC токенов**: RSA 2048-бит с алгоритмом RS256 (RFC 7518) и проверкой открытых ключей через JWKS (RFC 7517).
3. **Защита от перехвата авторизационного кода (PKCE)**: Алгоритм S256 с вычислением `BASE64URL-ENCODE(SHA256(code_verifier))` в соответствии с RFC 7636.
4. **Хранение секретов TOTP**: Симметричное шифрование Fernet (AES-128-CBC с аутентификацией HMAC-SHA256) с использованием изолированного ключа `TOTP_ENCRYPTION_KEY`; ротация требует перешифрования существующих ciphertext.
5. **Одноразовые токены и коды восстановления**: Необратимое хеширование SHA-256 (в базе данных сохраняются только хеши; открытые значения клиенту передаются однократно).
6. **Ротация Refresh Token с детектированием Replay**: Привязка токенов к `family_id`; при попытке использования ранее ротированного или отозванного токена аннулируются все активные токены семейства (SSO-05).

## 4. Входные и выходные данные

- **Входные данные**:
  - HTTP-запросы аутентификации (JSON, Form-Data);
  - Запросы OIDC потока Authorization Code (`client_id`, `redirect_uri`, `code_challenge`, `state`, `nonce`);
  - Bearer токены в заголовке `Authorization: Bearer <JWT>`.
- **Выходные данные**:
  - Структурированные ответы JSON со строгой схемой Pydantic;
  - Host-only cookies с идентификаторами сессий;
  - Заголовки ответов безопасности (HSTS, nosniff, DENY, CSP).
